What Endpoint360 Free Assesses

Seven read-only assessment modules examine Windows configuration, security, installed applications, updates, device health and network posture. Availability of individual checks depends on Windows permissions and system capabilities.

Windows OS & Updates

Operating system information, update history, pending Windows updates and reboot requirements.

Endpoint Security

Microsoft Defender, antivirus protection, signature status, firewall profiles and available Windows security controls.

Hardware & Device Health

Processor, memory, storage, device identity, system information and available hardware health indicators.

TPM, Secure Boot & Encryption

TPM availability, Secure Boot, firmware configuration and BitLocker protection status where accessible.

User & Access Security

Local user accounts, administrator membership, account settings and relevant access configuration.

Installed Software

Installed applications, publishers, versions and software inventory information available on the endpoint.

Network & Remote Access

Remote Desktop configuration, network adapters, firewall profiles, listening ports and SMB settings.

Configuration Compliance

Evidence-based configuration checks with documented assessment criteria, risk levels and remediation guidance.

Assessment Reports

Combined assessment data, control-level findings, practical recommendations and locally saved JSON reports.

Clear Findings. Practical Recommendations.

Endpoint360 provides results for 17 security controls, with available supporting evidence, risk levels and practical recommendations. A check may be Not Assessed when Windows permissions prevent collection.

PASS

The evaluated setting meets the defined check.

WARN

The setting requires further review or attention.

FAIL

The setting does not meet the defined check.

NOT CHECKED / NOT APPLICABLE

The setting could not be evaluated or does not apply to the endpoint.

Download the ZIP, extract all files, open the Endpoint360-Free folder and double-click Endpoint360Runtime.exe. Wait for the assessment, then view the local dashboard at 127.0.0.1:8765.

Privacy & Beta Notes

Assessment is read-only and reports are saved locally. Reports may include usernames, network and device details; review before sharing. Some security checks require administrator access. The executable is unsigned, so Windows may show a SmartScreen warning. Use only on devices you own or are authorized to assess.

Frequently Asked Questions

Is Endpoint360 available to download?

Yes. Endpoint360 Free v0.5.0 Public Beta is available for download. Extract the Windows ZIP and launch Endpoint360Runtime.exe from the extracted folder.

Is Endpoint360 different from V3.0.1?

Yes. Endpoint360 provides seven assessment modules, a local dashboard and 17 compliance controls. Endpoint Assessment v3.0.1 remains available as a lightweight alternative.

Will Endpoint360 change my Windows settings?

No. Endpoint360 Free v0.5.0 performs read-only checks and does not install updates or change Windows security settings.

Does Endpoint360 provide official compliance certification?

No. The assessment is informational and does not constitute official CIS, Microsoft or regulatory certification.
