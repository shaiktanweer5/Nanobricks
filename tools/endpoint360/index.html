Privacy & Security

Endpoint360 performs read-only assessments. It does not automatically install software, apply Windows updates, modify security settings or remediate findings.

Assessment reports are generated locally and saved under your Windows user profile.

Report location:

%LOCALAPPDATA%\Nanobricks\Endpoint360\reports

Some security checks, including TPM, Secure Boot and BitLocker, may show Not Assessed when additional Windows permissions are required.

Endpoint360 is an informational assessment tool. It does not provide formal compliance certification.

Frequently Asked Questions

Is Endpoint360 Free available to download?

Yes. Endpoint360 Free v0.5.2 beta is available as a single Windows EXE file.

Do I need to install Python?

No. The executable includes its required Python runtime. No separate Python installation is needed.

Do I need to extract a ZIP file?

No. Download NanobricksEndpoint360.exe and run the executable directly.

Is Endpoint360 different from Endpoint Assessment V3.0.1?

Yes. Endpoint360 provides seven assessment modules, a local dashboard and 17 compliance controls. Endpoint Assessment V3.0.1 remains a separate free tool.

Will Endpoint360 change my Windows settings?

No. Endpoint360 is a read-only assessment tool. It does not automatically change system configurations or install updates.

Where are assessment reports saved?

Reports are saved locally under %LOCALAPPDATA%\Nanobricks\Endpoint360\reports. They are not automatically uploaded to Nanobricks.

Why does the dashboard need the application window open?

The dashboard runs locally on your Windows computer. Keep the Endpoint360 application running while reviewing the assessment. Close the application window when finished.

Does Endpoint360 provide official compliance certification?

No. Results are informational configuration assessments, not official CIS, Microsoft or regulatory certification.
