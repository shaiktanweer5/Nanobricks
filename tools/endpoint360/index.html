What Endpoint360 Is Being Built to Check

The following assessment modules are planned for the Endpoint360 beta. Availability and coverage will be confirmed when the software is released.

Windows OS & Updates

Operating system edition, version, build, activation indicators, update history, pending patches and reboot requirements.

Endpoint Security

Microsoft Defender, antivirus protection, signature status, firewall profiles and available Windows security controls.

Hardware & Device Health

Processor, memory, storage, device identity, system information and available hardware health indicators.

TPM, Secure Boot & Encryption

TPM availability, Secure Boot, firmware configuration and BitLocker protection status where accessible.

User & Access Security

Local user accounts, administrator membership, account settings and relevant access configuration.

Installed Software

Installed applications, publishers, versions and software inventory information available on the endpoint.

Network & Remote Access

Remote Desktop, WinRM, selected remote access settings, listening ports and relevant network exposure.

Configuration Compliance

Evidence-based configuration checks with documented assessment criteria, risk levels and remediation guidance.

Assessment Reports

Structured technical findings, executive summaries, assessment evidence and exportable reports.

Clear Findings. Practical Recommendations.

Endpoint360 is planned to provide individual assessment results with supporting evidence, severity and recommended next steps.

PASS

The evaluated setting meets the defined check.

WARN

The setting requires further review or attention.

FAIL

The setting does not meet the defined check.

NOT CHECKED / NOT APPLICABLE

The setting could not be evaluated or does not apply to the endpoint.

Endpoint360 Development Status

We're preparing an initial Windows assessment beta. No Endpoint360 executable is available for download yet.

Currently in Development

The assessment collector, security checks, compliance evaluation and reporting features are planned for the first development phase. Functionality will be tested before public release.

Privacy & Safety by Design

The initial assessment is intended to be read-only and run with the device owner's authorization. No automatic remediation or silent configuration changes are planned.

Frequently Asked Questions

Is Endpoint360 available to download?

Not yet. Endpoint360 is currently in development. The download will be added after the initial application has been tested and released.

Is Endpoint360 different from V3.0.1?

Yes. Endpoint360 is planned as a more detailed Windows endpoint assessment tool. The existing Endpoint Assessment V3.0.1 remains available separately.

Will Endpoint360 change my Windows settings?

The initial beta is planned as a read-only assessment tool. Automatic remediation is not part of the initial scope.

Does Endpoint360 provide official compliance certification?

No. Planned configuration assessments are informational and will not constitute official CIS, Microsoft or regulatory certification.

How can I request a business assessment?

Contact Nanobricks through the website or WhatsApp to discuss Windows endpoint assessments and business IT requirements.
