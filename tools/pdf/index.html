Important

These tools use third-party open-source JavaScript libraries delivered through public CDN infrastructure.

PDF to Word is a browser-side text extraction converter. It does not perform OCR and does not promise layout-perfect conversion.

Avoid processing highly sensitive documents on any web tool unless permitted by your organization’s security and data-handling policies.

Frequently Asked Questions

Common questions about Nanobricks PDF Tools.

Are Nanobricks PDF Tools free?

Yes. The current tools are free and do not require a Nanobricks account.

Are my files uploaded to Nanobricks?

The current tools process selected documents in the browser and do not intentionally send them to a Nanobricks document-processing backend.

Can I convert PDF to Word?

Yes. The tool extracts selectable PDF text and creates a DOCX file. Complex layouts, scanned pages and tables may not be preserved exactly.

Can scanned PDFs be converted to Word?

Not yet. Scanned/image-only PDFs require OCR, which is not included in this browser-only release.

Can I extract page ranges?

Yes. Use formats such as 1,3,5-7 to create a new PDF from selected pages.

Are password-protected PDFs supported?

Password-protected or encrypted PDFs may not work in the current release.
