What the Assessment Checks

V3.0.1 performs a lightweight assessment of common Windows endpoint configuration, security and readiness indicators.

System Information

Reviews the hostname, Windows version, operating system build, processor, architecture, installed memory and disk capacity.

Microsoft Defender

Reviews Microsoft Defender availability, antivirus status, real-time protection and signature update information where available.

Windows Firewall

Reviews Windows Firewall profile status to identify whether the available firewall profiles are enabled.

Windows Updates

Checks the Windows Update service for pending updates that may require attention.

Microsoft Office

Detects Microsoft Office or Microsoft 365 installation details, version and platform where available.

Local Accounts

Reviews local Windows user accounts and local Administrators group membership to support account posture review.

Simple PASS / REVIEW / FAIL Results

The collected endpoint information is evaluated against the Nanobricks V3 assessment baseline and presented in a simple format to help identify areas that may require attention.

PASS

The assessed setting meets the current V3 baseline check.

REVIEW

The result may need administrative or operational review.

FAIL

The assessed setting does not meet the current V3 baseline check.

Privacy & Local Processing

Know what the V3.0.1 application does before running it.

Assessment reports stay local

Nanobricks Endpoint Assessment V3.0.1 runs its assessment on the Windows endpoint and saves the generated assessment output locally on that computer.

The packaged V3.0.1 application does not include functionality to upload the generated assessment report to Nanobricks or to a Nanobricks remote API.

The utility reads technical configuration information required for the assessment, including system information, Microsoft Defender status, Windows Firewall status, Windows Update status, Microsoft Office information, local Windows users and local administrator membership.

The generated report can contain internal technical information such as hostname, hardware information, security settings and local account names. Store and share the report appropriately.

Local Output

The application creates an endpoint-data folder beside the executable and saves:

<PC-NAME>-assessment.json
<PC-NAME>-assessment.html

Treat these files as internal IT assessment information.

Current V3.0.1 Scope

Understand what this utility is and what it is not.

What It Is

A lightweight Windows endpoint configuration and readiness assessment designed to provide a practical first-level view of common endpoint settings and security indicators.

What It Is Not

It is not an EDR, antivirus replacement, vulnerability scanner, penetration-testing tool or complete enterprise endpoint-management platform.

Assessment results are informational and should be reviewed against your organization's own security, compliance and operational requirements.

Frequently Asked Questions

Is the Endpoint Assessment really free?

Yes. V3.0.1 is available as a free Windows endpoint assessment utility.

Does Nanobricks receive my assessment report automatically?

No. The packaged V3.0.1 application saves the generated assessment output locally. It does not include functionality to upload the generated report to Nanobricks or to a Nanobricks remote API.

Does the assessment read my documents or personal files?

The V3 assessment is designed to collect technical system and configuration information required for the endpoint checks. It does not perform a scan of user document contents as part of the V3 assessment workflow.

Why might Windows show a SmartScreen warning?

The current V3.0.1 executable is not digitally signed using a commercial code-signing certificate. Windows may therefore show a SmartScreen reputation warning. Download from the official release and verify the published SHA-256 checksum.

Can I run it on multiple computers?

V3.0.1 assesses one Windows endpoint per execution. Businesses that need assessment across multiple PCs can contact Nanobricks for assessment and consolidated reporting services.

Does PASS mean the computer is completely secure?

No. PASS means the individual check met the current Nanobricks V3 baseline. A lightweight endpoint assessment cannot guarantee that a system is completely secure.

Can this replace antivirus, EDR or vulnerability management?

No. The utility is intended as a basic assessment and readiness tool, not a replacement for enterprise security technologies.
