Windows • Free V1 Utility • Local Assessment

What It Checks

A lightweight review of common Windows endpoint configuration and security indicators.

System Information

Windows version, processor, architecture, RAM and disk capacity.

Windows Security

Microsoft Defender, real-time protection and Windows Firewall profile status.

Windows Updates

Reviews the number of pending Windows updates.

Microsoft Office

Detects Microsoft Office or Microsoft 365 product, version and platform where available.

Local Accounts

Reviews local Windows users and local administrator membership.

Assessment Result

Reports PASS, REVIEW or FAIL against the Nanobricks V1 baseline.

How It Works

Three simple steps.

1

Download

Download NanobricksEndpointCollector.exe from the official GitHub release.

2

Run

Run the collector on a Windows computer you own or are authorized to assess.

3

Review

The collector creates:

endpoint-data\<PC-NAME>-assessment.json

Privacy & Local Processing

The V1 collector runs locally on the Windows endpoint.

It does not intentionally access user documents or file contents.

The assessment output can contain technical information such as hostname, hardware configuration, security settings, Office information and local account names. Treat the generated assessment file as internal IT information.

Current V1 Scope

Nanobricks Endpoint Assessment V1 is a lightweight configuration and readiness assessment utility.

It is not an EDR, antivirus replacement, vulnerability scanner or complete enterprise endpoint-management platform.

Assessment results are informational and should be reviewed based on your organization's security and operational requirements.
