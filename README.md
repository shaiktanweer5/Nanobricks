# Nanobricks

Official website repository for **Nanobricks**.

Nanobricks provides technology services for businesses, startups and institutions, including Managed IT, Cloud, Cloud Security, DevOps, Cybersecurity, Web & Software Solutions, and professional technology training through Nanobricks Academy.

Website: https://www.nanobricks.in

---

## Services

### Primary Services

- Managed IT & AMC
- Cloud Services
- Cloud Security
- DevOps & Automation
- Cybersecurity
- Web & Software Solutions

### Supporting Services

- Business IT Setup
- Backup & Business Continuity
- IT Consulting

### Nanobricks Academy

Nanobricks Academy is the learning and professional training division of Nanobricks.

Programs may include:

- Cloud Computing
- AWS
- Microsoft Azure
- Google Cloud
- Cloud Security
- DevOps
- Cybersecurity
- Python
- Software Development
- Workshops
- Internship Programs
- College Training Programs
