Frequently Asked Questions

What is a cloud security assessment?

It is a structured review of cloud identity, access, configuration, exposure, logging, backup and other security controls within the agreed environment.

Which cloud platforms do you support?

Nanobricks supports cloud security requirements across AWS, Microsoft Azure and Google Cloud depending on the agreed scope.

Can you review CNAPP or CSPM findings?

Yes. Findings from cloud security platforms can be reviewed, prioritized and mapped to practical remediation actions based on the engagement scope.

Do you provide remediation support?

Yes. Nanobricks can assist with agreed configuration changes, IAM improvements and cloud hardening activities.

Does a security assessment guarantee that our environment is secure?

No. A security assessment identifies risks observed during the engagement. Cloud environments continuously change, so security should be reviewed periodically.

How is cloud security pricing calculated?

Pricing depends on the cloud platform, number of accounts or subscriptions, environment size, security tooling, scope and remediation requirements.
