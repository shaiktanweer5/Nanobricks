Frequently Asked Questions

Common questions about Nanobricks Cloud Security Services.

What is a cloud security assessment?

It is a structured review of cloud identity, access, configurations, exposure, logging, backup and other security controls.

Which cloud platforms do you support?

Nanobricks supports cloud security requirements across AWS, Microsoft Azure and Google Cloud.

Can you review CNAPP or CSPM findings?

Yes. Findings can be reviewed, prioritized and translated into practical remediation actions based on the agreed engagement scope.

Do you provide remediation support?

Yes. Nanobricks can assist with agreed configuration changes, IAM improvements and cloud hardening activities.

Can you help with large volumes of cloud findings?

Yes. Findings can be prioritized using factors such as exposure, severity, identity context, workload importance and practical remediation impact.

Does an assessment guarantee that an environment is secure?

No. An assessment identifies risks observed during the engagement. Cloud environments continuously change, so security should be reviewed periodically.
