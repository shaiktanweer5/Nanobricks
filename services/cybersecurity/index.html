Frequently Asked Questions

Common questions about Nanobricks Cybersecurity Services.

What does a cybersecurity assessment include?

The exact scope depends on your environment, but it may include identity, access, endpoints, networking, vulnerabilities, backups, cloud configuration and security controls.

Can you help fix security findings?

Yes. Nanobricks can support agreed remediation activities such as access improvements, configuration changes and security hardening.

Do you support cloud security?

Yes. Nanobricks also provides dedicated cloud security services across AWS, Microsoft Azure and Google Cloud.

Do you provide vulnerability remediation support?

Yes. Existing vulnerability findings can be reviewed and prioritized, and remediation support can be provided based on scope.

Does a security assessment guarantee complete security?

No. An assessment identifies risks observed within the agreed scope and time period. Security should be continuously reviewed and improved.

How is cybersecurity pricing calculated?

Pricing depends on the number of systems, users, environments, assessment depth and remediation requirements.
